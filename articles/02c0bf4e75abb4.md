1Dでは、歯科医院向けのサブスク型動画配信サービス「1D」の開発・運用を行っております。

https://oned.jp/

## きっかけ
- 新規サービスをサブドメインで公開することとなり、既存プロジェクトでログインされていた際サブドメインでもログインされているステータスとしたい
- NextAuth(Auth.js)がBetter Authの管理下となり継続保守のみとなったので新規プロジェクトではBetterAuthを選定したい

## 既存プロジェクト(NextAuth)の改修

### NextAuthのauthOptionsに、Cookieの設定を追加

Cookieのドメインを`example.com`から`.example.com`に変更することで認証のCookieをサブドメインでも共有できるように変更

```ts:project/auth.ts
export const authOptions = {
  ...
  cookies: {
    sessionToken: {
      name: 'next-auth.session-token',
      options: {
        domain: '.example.jp', // Cookieをサブドメインでも共有できるように変更
        httpOnly: true,
        maxAge: 60 * 60 * 24 * 30,
        path: '/',
        sameSite: 'lax',
        secure: process.env.APP_ENV !== 'development',
      }
    }
    // ※ next-auth.csrf-token, next-auth.callback-url も同様に
  }
}
```

:::message alert
ドメインを変更しているため、ログインユーザーは強制的にログアウトされるのでご注意ください
:::

## 新規プロジェクト(BetterAuth)の実装

### Better Auth の初期設定

#### Better Auth のインストール

```shell
npm i better-auth
```

#### API Routeの作成

```ts:new_project/app/api/auth/[...all]/route.ts
import { toNextJsHandler } from 'better-auth/next-js'

import { auth } from '@/libs/auth'

export const { GET, POST } = toNextJsHandler(auth)
```

#### Better Auth Configの設定
```ts:new_project/app/libs/auth/index.ts
import { betterAuth } from 'better-auth'
import { nextCookies } from 'better-auth/next-js'
import { jwt } from 'better-auth/plugins'

const isProduction = process.env.APP_ENV === 'production'

export const auth = betterAuth({
  advanced: {
    // ドメイン間でのCookieの共有の設定
    crossSubDomainCookies: {
      domain: isProduction ? '.example.com' : '.example.local',
      enabled: true,
    },
    useSecureCookies: isProduction,
  },
  emailAndPassword: {
    enabled: false,
  },
  plugins: [
    // Better Auth Plugin
    jwt(),
    nextCookies(),

    // 独自Pluginの実装

  ],

  secret: process.env.BETTER_AUTH_SECRET,

  // セッション設定（NextAuthと同様の設定に）
  session: {
    cookieCache: {
      enabled: true,
      maxAge: 60 * 5, // 5分間キャッシュ
      strategy: 'jwe',
    },
    expiresIn: 60 * 60 * 24 * 30, // 認証有効期間
    updateAge: 60 * 60 * 24, // 1日ごとにセッション更新
  },

  // 信頼するオリジン
  trustedOrigins: [
    serverEnv.BETTER_AUTH_URL,
    isProduction ? 'https://example.com' : 'http://example.local:3000',
    isProduction ? 'https://shop.example.com' : 'http://shop.example.local:3001'
  ],
})
```
