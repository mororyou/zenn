## はじめに

1Dでは、歯科医院向けのサブスク型動画配信サービス「1D」の開発・運用を行っております。

https://oned.jp/

開発に利用している技術などについては、以下の記事をご覧ください。

https://zenn.dev/kamayla/articles/oned-tech-select

## きっかけ
- 新規サービスをサブドメインで公開することとなり、既存プロジェクトでログインされていた際サブドメインでもログインされているステータスとしたい
- APIは共通のエンドポイント（GraphQL）を利用し開発コストを削減する
- NextAuth(Auth.js)がBetter Authの管理下となり継続保守のみとなったので新規プロジェクトではBetterAuthを選定したい

---

プロジェクトのディレクトリやドメインは以下の通りとする

| プロジェクト名 | ディレクトリ名 | ドメイン | 
| ---- | ---- |---- |
| 既存プロジェクト | project | example.com |
| 新規プロジェクト | new_project | shop.example.com |

## 既存プロジェクト(NextAuth)の改修

### NextAuthのauthOptionsに、Cookieの設定を追加

Cookieのドメインを`example.com`から`.example.com`に変更することで認証のCookieをサブドメインでも共有できるように変更

```ts:project/auth.ts
export const authOptions = {
  ...
  cookies: {
    sessionToken: {
      name: 'next-auth.session-token', // 任意のCookie名
      options: {
        domain: '.example.jp', // Cookieをサブドメインでも共有できるように変更
        httpOnly: true,
        maxAge: 60 * 60 * 24 * 30,
        path: '/',
        sameSite: 'lax',
        secure: process.env.APP_ENV !== 'development',
      }
    }
    // ※ next-auth.csrf-token, next-auth.callback-url も同様に
  }
}
```

:::message alert
ドメインを変更しているため、ログインユーザーは強制的にログアウトされるのでご注意ください
:::

## 新規プロジェクト(BetterAuth)の実装

### 新規プロジェクトの.envの設定

のちに説明するJWEの暗号・復号化に利用するため、既存プロジェクトのprojectのNEXTAUTH_SECRETと同様の値を設定する必要性があるので注意が必要となります。


#### Better Auth Configの設定
```ts:new_project/app/libs/auth/index.ts
import { betterAuth } from 'better-auth'
import { nextCookies } from 'better-auth/next-js'
import { jwt } from 'better-auth/plugins'

const isProduction = process.env.APP_ENV === 'production'

export const auth = betterAuth({
  advanced: {
    // ドメイン間でのCookieの共有の設定
    crossSubDomainCookies: {
      domain: isProduction ? '.example.com' : '.example.local',
      enabled: true,
    },
    useSecureCookies: isProduction,
  },
  emailAndPassword: {
    enabled: false,
  },
  plugins: [
    // Better Auth Plugin
    jwt(),
    nextCookies(),
  ],

  secret: process.env.BETTER_AUTH_SECRET,

  // セッション設定（NextAuthと同様の設定に）
  session: {
    cookieCache: {
      enabled: true,
      maxAge: 60 * 5, // 5分間キャッシュ
      strategy: 'jwe',
    },
    expiresIn: 60 * 60 * 24 * 30, // 認証有効期間
    updateAge: 60 * 60 * 24, // 1日ごとにセッション更新
  },

  // 信頼するオリジン
  trustedOrigins: [
    serverEnv.BETTER_AUTH_URL,
    isProduction ? 'https://example.com' : 'http://example.local:3000',
    isProduction ? 'https://shop.example.com' : 'http://shop.example.local:3001'
  ],
})
```

### JWEのユーティリティを作成

#### JWEとは・・・？
暗号化したデータを、復号に必要なメタデータとあわせて JSON 形式でパッケージするデータ表現形式です。

NextAuthでは内部で、`@panva/hkdf`, `jose`を利用しJWTの暗号化(JWE)を実装されている。
https://github.com/nextauthjs/next-auth/blob/v4/packages/next-auth/src/jwt/index.ts

```ts:new_project/libs/auth/jwe.ts
import hkdf from '@panva/hkdf'
import { EncryptJWT, jwtDecrypt } from 'jose'

/**
 * JWE 暗号化/復号化ユーティリティ
 * NextAuth と完全互換の設定を使用
 */

// NextAuth と同じ暗号化設定
const ENCRYPTION_ALG = 'dir' as const
const ENCRYPTION_ENC = 'A256GCM' as const

/**
 * NextAuth と完全に同じ方法でキーを導出
 * @panva/hkdf を使用（NextAuth と同じライブラリ）
 */
async function getDerivedEncryptionKey(
  secret: string,
  salt: string = '',
): Promise<Uint8Array> {
  // NextAuth と完全に同じ実装
  // https://github.com/nextauthjs/next-auth/blob/v4/packages/next-auth/src/jwt/index.ts
  const info = `NextAuth.js Generated Encryption Key${salt ? ` (${salt})` : ''}`
  const key = await hkdf('sha256', secret, salt, info, 32)
  return key
}


/**
 * セッションデータを JWE で暗号化（NextAuth 互換）
 * @param payload - 暗号化するペイロード
 * @param secret - シークレット文字列（BETTER_AUTH_SECRET）
 * @param salt - ソルト（オプション）
 * @param maxAge - トークンの有効期限（秒）
 */
export async function encryptJwe<T extends Record<string, unknown>>(
  payload: T,
  secret: string,
  salt: string = '',
  maxAge: number = 60 * 60 * 24 * 30, // 30日
): Promise<string> {
  const encryptionKey = await getDerivedEncryptionKey(secret, salt)
  const now = Math.floor(Date.now() / 1000)

  const jwe = await new EncryptJWT(payload)
    .setProtectedHeader({ alg: ENCRYPTION_ALG, enc: ENCRYPTION_ENC })
    .setIssuedAt(now)
    .setExpirationTime(now + maxAge)
    .setJti(crypto.randomUUID())
    .encrypt(encryptionKey)

  return jwe
}

/**
 * JWE を復号化してセッションデータを取得（NextAuth 互換）
 * @param jwe - JWE トークン
 * @param secret - シークレット文字列（BETTER_AUTH_SECRET）
 * @param salt - ソルト（オプション）
 */
export async function decryptJwe<T>(
  jwe: string,
  secret: string,
  salt: string = '',
): Promise<T | null> {
  try {
    const encryptionKey = await getDerivedEncryptionKey(secret, salt)
    const { payload } = await jwtDecrypt(jwe, encryptionKey, {
      clockTolerance: 15, // NextAuth と同じ許容範囲
    })
    return payload as T
  } catch {
    return null
  }
}

```
### 独自エンドポイントプラグインの作成

独自のエンドポイント`/api/auth/origin-session` や `/api/auth/origin-sign-in`などのエンドポイントを作成し、JWEの暗号化や復号化などの処理を実装する

```ts:new_project/app/libs/auth/origin-plugin.ts

// Cookie名の設定
// next-auth.session-tokenの部分は任意であり、project/auth.tsで設定したCookie名と統一する必要性あり
export const SESSION_COOKIE_NAME =
  `${process.env.APP_ENV === 'production' && '__Secure-'}next-auth.session-token`

export const COOKIE_OPTIONS = {

}

export cosnt orignEndpointPlugin = () => {
  return {
    endpoints: {
      // セッションを取得するエンドポイントを作成
      orignSession: createAuthEndpoint(
        "origin-session", // セッションのエンドポイント
        {
          method: "GET" //
        },
        async (ctx) => {
          // JWE 暗号化された Cookie からセッション情報を取得
          const encryptedCookie = ctx.getCookie(SESSION_COOKIE_NAME)

          if (!encryptedCookie) {
            return ctx.json(null)
          }

          // JWE を復号化（NextAuth 互換）
          const sessionData = await decryptJwe<NextAuthSessionData>(
            encryptedCookie,
            ctx.context.secret,
            // NextAuth では salt は空文字列がデフォルト
          )

          if (!sessionData) {
            // 復号化に失敗した場合は Cookie を削除して null を返す
            ctx.setCookie(SESSION_COOKIE_NAME, '', {
              ...COOKIE_OPTIONS
              maxAge: 0,
            })
            return ctx.json(null)
          }

          return ctx.json({
            session: {
              token: sessionData.token,
            },
            user: sessionData.user,
          })
        }
      ),
      // サインインのエンドポイントを作成
      orignSignIn: createAuthEndpoint(
        "origin-sign-in", // セッションのエンドポイント
        {
          method: "GET" //
        },
        async (ctx) => {
          // 
          try {
            // ログインのAPIを叩く
            const loginResponse = await client().mutate<
              User_LoginMutation,
              User_LoginMutationVariables
            >({
              mutation: USER_LOGIN,
              variables: {
                input: {
                  email: ctx.body.email,
                  password: ctx.body.password,
                },
              },
            })

            if (!loginResponse.data) {
              throw new Error('ログインに失敗しました')
            }

            const { token, user } = loginResponse.data.userLogin

            // セッションデータを JWE で暗号化（NextAuth 互換）
            const sessionData: NextAuthSessionData = {
              token: token,
              user: user,
            }
            const encryptedSession = await encryptJwe(
              sessionData,
              ctx.context.secret,
              // NextAuth では salt は空文字列がデフォルト
            )

            // 暗号化されたセッションを Cookie に保存
            ctx.setCookie(
              SESSION_COOKIE_NAME,
              encryptedSession,
              COOKIE_OPTIONS,
            )

            return ctx.json({
              message: 'ログインに成功しました',
            })

          } catch (error) {
            throw error
          }
        }
      ),
      // サインアウトのエンドポイントを作成
      orignSignOut: createAuthEndpoint(
        "origin-sign-out", // セッションのエンドポイント
        {
          method: "GET" //
        },
        async (ctx) => {
          // Cookie を削除
          ctx.setCookie(SESSION_COOKIE_NAME, '', {
            ...COOKIE_OPTIONS,
            maxAge: 0,
          })
          return ctx.json({ message: 'サインアウトに成功しました' })
        }
      ),
      // サインアップのエンドポイントを作成
      orignSignUp: createAuthEndpoint(
        "origin-sign-up", // セッションのエンドポイント
        {
          method: "GET" //
        },
        async (ctx) => {
          // Todo: ...
        }
      ),
    }
  }
}
```
